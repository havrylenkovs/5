# Котосфера — тестовий лендінг

Простий статичний сайт про Фелісетт — першу кішку в космосі. Працює без фреймворків і має темну та світлу теми.

## Як редагувати

- Тексти та блоки: `index.html`
- Кольори й оформлення: `styles.css`
- Перемикач теми: `script.js`
- Головне зображення: `assets/space-cat.jpg`

Після зміни файлів у гілці `main` GitHub Actions автоматично оновить GitHub Pages.
